# Open science badges

The official badges of the Center for Open Science, from the files it
publishes at <https://osf.io/tvyxz/files/>, where they are offered free to use
with attribution to the Center.

- `*.pdf`: cut, as vector art, from `OpenScienceBadges_all.eps` (the large
  colour badge of each kind, converted with `epstopdf`).
- `open-code.png`, `preregistered-plus.png`: the two badges that sheet does not
  have, trimmed from `Wiki images/open-code.png` and
  `Preregistered Badge Image Files/preregisteredplus_large_color.png`.

TC is Transparent Changes and DE is Data Exist, the notations the Center adds
to a preregistration badge. See its criteria for each badge before showing one.
